Research-stage Layer-1 engineering · no live chain

APEX Protocol

Rustrevm 43.0.3redb persistenceEd25519Validator lifecycleFault-injection testing

A Rust Layer-1 protocol engineering project with executable infrastructure prototypes across EVM execution, state management and validator safety. Implemented modules include full-width EVM state snapshots and a revm database adapter, an in-memory contract deploy/call harness, bounded parent-version-bound state-diff extraction, and versioned redb persistence prototypes. The codebase also contains account-scoped SHA-256 Merkle inclusion/non-inclusion proofs, experimental Ed25519 validator and commit-certificate verification, durable anti-double-sign reservations, a validator-lifecycle state machine, monotonic checkpoint storage, and a separate HTTP witness service with an HTTPS/mTLS client. A multi-process harness exercises partition, message-ordering, restart and replay fault scenarios; Malachite finality integration remains isolated research code. This is not a functioning blockchain: there is no integrated BFT runtime, production validator network, authenticated end-to-end transaction pipeline, block production, live testnet/mainnet or production finality. The node executable is a fail-closed lifecycle preflight, not a running chain node.

How I work

Architecture is a tool for making better product and engineering decisions—not an end in itself.

I work from the problem outward: understand users and operating constraints, map the system and its failure modes, choose a proportionate architecture, then build and validate in increments.

My interests include AI-enabled products, fintech infrastructure, offline-first systems, multi-tenant SaaS and mobile experiences for markets where connectivity, device capability and cost are real design constraints.

I value clear technical evidence: working software, meaningful tests, secure defaults, observable behaviour and honest statements about what is shipped versus what is still being developed.

Design for failurePlan for network loss, provider outages and partial system failures.
Security by designBuild authorization, privacy and auditability into system boundaries.
Evidence over claimsUse tests, measurable outcomes and transparent project status.
Product before noveltyApply AI and complexity only where they create user value.
